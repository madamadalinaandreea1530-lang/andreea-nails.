PASUL 1 – SUPABASE
1. Deschide: https://supabase.com/dashboard/project/wkchngcbghkwyvvwyoam/sql/new
2. Deschide fisierul migration_andreea_nails_calendar.sql din arhiva.
3. Copiaza tot continutul in SQL Editor si apasa RUN.
4. Continua numai daca apare Success. Daca apare eroare, opreste-te si trimite mesajul exact; nu rula din nou alte migrari vechi.

PASUL 2 – GITHUB
1. Descarca si dezarhiveaza aceasta arhiva.
2. Deschide repository-ul: https://github.com/madamadalinaandreea1530-lang/andreea-nails
3. Incarca fisierele din arhiva in radacina repository-ului si confirma inlocuirea fisierelor cu acelasi nume:
   index.html, admin.html, app.js, admin.js, style.css, config.js
4. Pastreaza si fisierele/folderul supabase/functions deja existente. Arhiva include functiile de e-mail din versiunea anterioara.
5. Nu sterge alte fisiere din repository.

PASUL 3 – CLOUDFLARE
1. Deschide https://dash.cloudflare.com/ si proiectul Pages andreeanailtech.
2. Asteapta deploy-ul automat pornit de GitHub.
3. Deschide https://andreeanailtech.pages.dev si reincarca pagina.

PASUL 4 – ADMINISTRARE
1. Deschide https://andreeanailtech.pages.dev/admin.html si autentifica-te.
2. In „Ore disponibile pe data”, alege data si ora, apoi „Adauga ora”. Repeta pentru fiecare ora.
3. In „Personalizare design”, alege tema (bej & auriu, vara, toamna, primavara sau Craciun), modifica textele disponibile si salveaza.
4. Deschide pagina publica si reincarca pentru a vedea schimbarile.
